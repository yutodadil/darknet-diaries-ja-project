# Darknet Diaries 日本語翻訳プロジェクト

[Darknet Diaries](https://darknetdiaries.com/)は、サイバーセキュリティやハッキングの実話を取り上げる、Jack Rhysiderによるポッドキャストです。この非公式プロジェクトでは、日本語で過去の事件を学べる読み物を目指しています。

## 読む

- [第1回から読む](Episode-1.md)
- [全エピソード一覧・翻訳状況](EPISODES.md)
- [訳語の修正と校閲の記録](TRANSLATION_NOTES.md)

各エピソードはMarkdown形式です。冒頭の目次から章へ移動でき、章末から目次に戻れます。ページ下部には前後の翻訳済みエピソードへのリンクがあります。章は日本語版の読みやすさのために付けたもので、音声のタイムスタンプではありません。

## 更新状況

2026年10月9日確認時点の最新の通常回は、第180回「Conti」（2026年10月6日公開）です。

| 範囲 | 状態 |
| --- | --- |
| 第1〜13回 | 既存訳をMarkdown化・章立て。一部の誤訳と表現を修正。全文校閲は未完了 |
| 第14〜180回 | 一覧に公式タイトル・公開日・再生時間・公式リンクを追加。日本語本文は未収録 |
| ボーナス回・有料回 | 今回の一覧の対象外 |

一覧の更新と翻訳本文の完成は別々に管理しています。未翻訳回には、翻訳済みと誤解される空の本文ファイルを置いていません。

既存訳はChatGPT-4oで作成されました。今回の修正箇所は[校閲の記録](TRANSLATION_NOTES.md)を参照してください。本文の「現在」や金額、サービス・制度の説明は、原則として番組収録・追記当時のものです。

## 翻訳・校閲への参加

新しい翻訳や既存訳の修正は、Issue・PRで受け付けています。修正時は回番号、該当章、英語の該当箇所、修正理由を添えてください。話者の推測や意見を確定した事実に置き換えず、皮肉・比喩・確信の度合いを保つことを重視します。

- [公式のエピソード一覧](https://darknetdiaries.com/episode/)
- 各ページ上部の英語文字起こしリンク
- [DarknetDiariesTranscriptDownloader](https://github.com/iamthefrogy/DarknetDiariesTranscriptDownloader)：原文取得を補助する外部ツール

新しい本文には、原文の出典と日本語版の校閲状況を明記してください。原文をダウンロードできることと、翻訳の公開に利用できることは別のため、公開に使える原文・条件を確認してから追加してください。

## 構成とチェック

- `Episode-N.md`：日本語本文、章目次、前後の回へのリンク
- `EPISODES.md`：第1〜180回の一覧と翻訳状況
- `data/episodes.json`：確認日と公式の公開メタデータ
- `TRANSLATION_NOTES.md`：校閲の範囲、訳語、修正記録

Python 3.10以降で、目次・ファイルリンク・収録番号・メタデータの整合性を確認できます。

```sh
python scripts/check_content.py
```

このチェックは翻訳の意味や外部リンク先の稼働状況を判定しません。翻訳本文は別途原文と照合してください。
